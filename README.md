## Project Overview
My **Portfolio** is a modern, responsive web application built to showcase my academic background, technical skill set and practical experiences. Designed with a focus on UI/UX aesthetics, the platform serves as an interactive resume and personal brand space to demonstrate my capabilities in software development, visual design, and system analysis.

---

## Key Features
* **Responsive & Mobile-Friendly Layout:** Smoothly adapts to desktop, tablet, and mobile devices with custom touch-friendly scrolling cards.
* **Dark & Light Mode Toggle:** Seamless theme switcher with `LocalStorage` support to remember user preferences across sessions.
* **Interactive Hero Section:** Dynamic 3D profile picture effect, live typing animation for roles, and quick status metrics.
* **Comprehensive Academic & Skill Highlights:** Clear presentation of CGPA, Dean's List honors, professional certifications, and technical skills.
* **Particle Background Animation:** Powered by tsParticles for an engaging, gold-themed interactive background.
* **Direct Contact Integration:** One-click links for Email, WhatsApp/Phone, LinkedIn, GitHub, and location references.
